# Ronins

Ronins is an AI visual studio for film and series makers. We create AI-generated
photos and videos that help creative teams build stronger worlds, pitch ideas
more vividly, and make their stories more impactful.

## Contact form setup

The project form is hosted at `contact.html`. The Netlify function stores each
submission in Supabase and sends an email notification with Resend.

Create a Supabase table named `project_inquiries` with:

```sql
create table project_inquiries (
  id bigint generated by default as identity primary key,
  created_at timestamptz default now(),
  name text not null,
  email text not null,
  company text,
  project_type text not null,
  service text not null,
  message text not null
);
```

In Netlify, add these environment variables:

- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`
- `RESEND_API_KEY`
- `CONTACT_EMAIL` (optional; defaults to `ramezazar.raa@gmail.com`)
- `RESEND_FROM` (optional; use a verified Resend sender)

Deploy the repository as a Netlify site. Netlify automatically detects the
function in `netlify/functions/submit-contact.js`. Never expose the Supabase
service-role key in frontend code.
